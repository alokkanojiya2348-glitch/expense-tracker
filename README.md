# Expense Tracker

A modern and responsive expense tracker web application built with React, Vite, and Tailwind CSS. Track income, expenses, view breakdown charts, and filter transactions effortlessly.

## Features

- **Transaction Management:** Add, edit, and delete income and expense transactions.
- **Visual Analytics:** Interactive charts for expense breakdown by category.
- **Filters & Search:** Filter transactions by category, type, and date.
- **Summary Dashboard:** Real-time calculation of total balance, income, and expenses.

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
   *(or `bun install`)*

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
